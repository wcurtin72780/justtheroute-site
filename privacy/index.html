Just the Route

Privacy Policy

Last updated November 7, 2026

The short version

This site is a static archive of running routes and race-day videos. It has no user accounts and sets no tracking cookies of its own. Two features do involve information: the route suggestion form, and a private stats widget the channel owner uses to keep an eye on the channel. Both are described below, in plain language.

The website

The site is hosted on Cloudflare Pages. Like most web hosts, Cloudflare may keep standard server logs (pages requested, timestamps, and approximate location derived from an IP address) to run and protect the service. Videos live on YouTube; anything you watch or do there is governed by YouTube's and Google's own privacy policies. GPX downloads are plain files and ask for nothing.

Route suggestions

If you use the Suggest a Route form, the name you give (optional) and your suggestion are emailed to the channel inbox through FormSubmit so the owner can read them. Suggestions are read by a person, not sold, rented, or shared with marketers.

The channel stats widget

The owner uses a small desktop program, the JustTheRoute Widget, that shows the channel's own subscriber count, total views, and lifetime watch hours on his computer. To do that, the widget signs in with the owner's own Google account and reads the owner's own YouTube channel data through Google's YouTube Data API and YouTube Analytics API, using a read-only permission.

The sign-in token and API key are stored only on the owner's own computer. The channel figures the widget displays stay on that computer. Nothing is uploaded anywhere, sold, or shared with any third party.

The widget's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The owner can revoke the widget's access at any time from his Google account's permissions page.
